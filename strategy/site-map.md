# Карта сайта и конверсионная логика

## Основной путь

Главная → релевантный кейс → услуга / процесс → контакт.

## Вторичные пути

- Поиск → статья → услуга → кейс → контакт.
- Поиск по Калининграду → локальная услуга → портфолио → контакт.
- Портфолио → конкретный кейс → похожая услуга → контакт.

## Страницы

- `/` — позиционирование, избранные проекты, услуги, подход, процесс, блог, CTA.
- `/portfolio.html` — полный список пяти концептов, expertise, процесс, CTA.
- `/portfolio/{slug}/` — пять индексируемых историй проектов.
- `/services.html` — общая коммерческая страница и подтверждённые стартовые цены.
- Шесть тематических страниц услуг — отдельные поисковые намерения без дублирования общей страницы.
- `/about.html` — роль, подход, навыки, инструменты и ценности без выдуманной биографии.
- `/blog/` и 12 статей — ответы на вопросы до обращения.
- `/contact.html` — форма и прямые контакты.
- `/privacy.html` — черновик сведений о форме и сторонних сервисах.
