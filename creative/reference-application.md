# Применение референсов для кейса WAYPOINT

## Использованный ориентир

- `residential-green-bento` из личной библиотеки: переносится только принцип «крупное содержательное изображение + короткое конкретное пояснение». Локального оригинала и публичной ссылки для точного разбора нет.

## Что перенесено

- Первому экрану отдана роль главного доказательства проекта.
- Фотографии используются как содержательный материал, а не декоративный фон.
- Текст карточки коротко объясняет назначение и ключевые сценарии.

## Что сознательно не использовано

- Не перенесены бенто-сетка, палитра, фирменные элементы или конкретная структура референса: портфолио уже имеет собственную сетку и визуальную систему.

## Fingerprint набора

`existing-portfolio-grid + authentic-project-screens + one-dominant-cover`
