Авторская правка поверх 967a556: личные заметки редактируются в src/notes.mjs, общая разметка в renderNote / noteList / marginNote файла src/render.mjs. Стили находятся под комментарием Personal edition в site.css. Чтобы добавить заметку, заполнить объект по существующему формату и выполнить npm run test; её маршрут, список и sitemap создаются сборкой. Дату и личные утверждения согласовывать с владельцем. После добавления страницы обновить ожидаемое число URL в tests/site-audit.mjs.

Jura 600 и обе части Onest локальные, с preload в общем head. В текущей правке JavaScript и зависимости не менялись. Авторская пометка не использует JS. Подробности лабораторной проверки загрузки и её пределы: reports/personal-2026-09-06.md.

Эффект печатной машинки находится на `em[data-typewriter]` в hero и запускается из `site.js`. Полная фраза остаётся в исходном HTML; при `prefers-reduced-motion: reduce` скрипт не запускает таймеры и текст остаётся видимым сразу. Скорость задаётся в одном месте рядом с `typeNext`.

- Источники страниц: `src/render.mjs`, контент: `src/site-data.mjs`, `src/articles*.mjs`.
- Стили: `site.css`. Новый авторский стиль выделен комментарием Portfolio edition; исходные компоненты внутренних страниц сохранены.
- Интерактивность: `site.js`; меню и старые hash-адреса сохранены, добавлено управление клавиатурным фокусом.
- `npm run build` генерирует HTML в корне и `dist/client`, обновляет sitemap. После изменения исходников нужно пересобрать и отправить исходники вместе с HTML в main.
- Шрифт Onest хранится в `assets/fonts`; открытая лицензия OFL приложена. Запросов к Google Fonts во время посещения нет.
- Исходные PNG сохранены. Для обложек и портрета добавлены WebP, используемые через srcset. Суммарно 13 524 067 → 955 792 байта для оптимизированного набора (−93%); это не измерение скорости страницы.
- Изображения ПУЛЬС продолжают загружаться с существующего публичного проекта.
- `config.js`, Supabase admin, CNAME, тексты статей, цены и контакты не изменены.
- Откат: revert коммита редизайна и повторная публикация Pages. Не применять принудительный push.

Юридические пределы: права на исходные материалы и существующая политика остаются ответственностью владельца; новых коммерческих метрик, отзывов, форм, трекеров и внешних сборщиков данных не добавлено.
