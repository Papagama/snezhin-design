# Design guardrails

- Container: максимум 1280 px; desktop 12 колонок; поля 24–56 px; mobile поля 18–24 px.
- Основные интервалы: 8, 12, 16, 24, 32, 48, 72, 96, 144 px.
- H1: `clamp(3.4rem, 9vw, 9.5rem)`; H2: `clamp(2.2rem, 5vw, 5.8rem)`; body 17–20 px; длина строки 62–72 символа.
- Цвета: тёплый paper `#fff6e8`, ink `#17113a`, muted `#5f587c`, line `#c9bde4`, action-blue `#155eef`, electric-blue `#2735c7`, жёлтый `#f4c542`, лайм `#b6e34d`, dark `#25124e`. Яркие оттенки кодируют действие и ритм, а не используются случайно; розовые декоративные акценты исключены.
- Радиусы: 0 для контентных блоков, 999 px только для компактных кнопок/меток; никаких универсальных rounded-card.
- Тени не используются как постоянный декор; допустима только тень мобильного меню.
- Карточки проектов не должны иметь одинаковые размеры подряд.
- Изображения всегда имеют `width`, `height`, `object-fit` и содержательный alt.
- Анимация 160–240 мс; transform/opacity; без layout shift; reduced-motion отключает переходы.
- Focus ring контрастный и видимый; touch target минимум 44×44 px.
