# Обновлённое портфолио Кирилла Снежина

Создано 6 сентября 2026. Сохранены структура и адреса сайта, пять концептов, услуги, блог и контакты.

Идея: показать автора и уровень работ через крупный типографический первый экран, компактный портрет и галерею с разным масштабом проектов. Светлая основа, графитовый текст, оранжевый акцент. Внутренние страницы используют ту же систему.

Проверено: все публичные HTML-страницы, ссылки, мобильная версия, меню, FAQ, навигация с клавиатуры, режим без JavaScript и загрузка изображений. Дизайн готов к показу клиентам (Client Ready). Публикация выполняется по прямому запросу владельца на существующем GitHub Pages.

Что остаётся гипотезой: влияние нового оформления на обращения. После запуска оценивайте реальные обращения и вопросы посетителей. Проверяйте актуальность цен, своих контактов и исходных материалов; не добавляйте показатели результатов без подтверждения.

Для редактирования и обслуживания: `technical/technical-handoff.md`. Дизайн-обоснование: `creative/redesign-2026-09-05/`. Проверки: `tests/visual-qa.md`, `tests/functional-qa.md`.
